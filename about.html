About NetFilm

NetFilm is a practice project to demonstrate building modern websites using Bootstrap 5, HTML, CSS and JavaScript. This mini-app includes pages for Home, Movies, About, and Favorites. Use filters, search, and save favorite movies to your browser's local storage.

Objective
  • Practice layout, responsive grid and navigation.
  • Create reusable components (movie cards).
  • Implement lightweight interactivity with JS.
